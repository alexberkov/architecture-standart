| Код | Требования                                                                                  | Комментарий                                        |
|-----|---------------------------------------------------------------------------------------------|----------------------------------------------------|
| F   | Функциональные (Functionality)                                                              |                                                    |
| F1  | Клиент может видеть список доступных депозитов и актуальных ставок на сайте банка           |                                                    |
| F2  | Клиент может подать заявку на депозит на сайте банка, оставив свой номер телефона и Ф. И. О |                                                    |
| F3  | Менеджер кол-центра может видеть заявки, оставленные клиентами                              |                                                    |
| F4  | Клиент может видеть в интерент-банке персонализированные ставки по доступным депозитам      |                                                    |
| F5  | Клиент может подать заявку на открытие депозита в интернет-банке                            |                                                    |
| F6  | Клиент может подтвердить открытие депозита с помощью СМС-кода                               |                                                    |
| F7  | Сотрудники бэк-офиса могут просматривать/изменять текущие ставки по депозитам в АБС         |                                                    |
| F8  | Сотрудник бэк-офиса может подтвердить условия депозита по заявке клиента в АБС              |                                                    |
| F9  | Клиент получает СМС-уведомление о подтверждении условий депозита                            |                                                    |
| U   | Удобство использования (Usability)                                                          |                                                    |
| U1  | Внешний вид приложений должен соответствать системе дизайна, принятой в компании            |                                                    |
| R   | Надёжность (Reliability)                                                                    |                                                    |
| R1  | Режим работы всех сервисов - 24/7                                                           |                                                    |
| R2  | Требуемый уровень доступности системы - 99,9%                                               |                                                    |
| P   | Производительность (Performance)                                                            |                                                    |
| P1  | Отклик по любым операциям должен занимать несколько миллисекунд                             |                                                    |
| P2  | Загрузка данных при проведении платежей должна занимать не больше секунды.                  |                                                    |
| S   | Поддерживаемость (Supportability)                                                           |                                                    |
| S1  | Для системы должна быть разработана документация                                            |                                                    |
| S2  | Cистема должна иметь возможность горизонтального масштабирования                            | АБС может масштабироваться только вертикально      |
| S3  | Cистема должна иметь возможность балансировки запросов между серверами, приложениями и ЦОД  |                                                    |
| +R  | + Ограничения (Restrictions)                                                                |                                                    |
| +R1 | Данные клиентов должны быть зашифрованы при передачи с сайта                                |                                                    |
| +R2 | Функционал работы с СМС должен быть реализован в ядре системы                               |                                                    |
| +R3 | Данные клиентов должны быть зашифрованы при передачи из интернет-банка                      |                                                    |
| +R4 | В качестве БД системы должны использоваться MS SQL и Oracle                                 |                                                    |
| +R5 | В качестве очереди сообщений должна использоваться Kafka                                    | Текущая версия интернет-банка несовместима с Kafka |
| +R6 | Должна использоваться микросервисная архитектура                                            | Только в рамках задачи открытия депозитов          |
| +R7 | Сервисы сайта и интернет-банка не должны обращаться к API АБС напрямую                      | Текущая база данных АБС перегружена                |
